# Fiche pédagogique — Parcours cardiologie ambulatoire

Source : *FICHE PÉDAGOGIQUE EXTERNES – parcours ambulatoire* (PDF IMM).

**Public :** 2e cycle  
**Organisation :** apprentissage supervisé en petits groupes  

**Activités :**
1. Consultation de cardiologie et présentation d’un dossier clinique  
2. Échocardiographie transthoracique (ETT)

**Objectif général :** compétences cliniques et paracliniques fondamentales pour l’évaluation initiale d’un patient avec problématique cardiovasculaire fréquente.

---

## 1. Consultation et présentation d’un dossier

À l’issue de la rotation, l’étudiant doit pouvoir :
- recueillir une histoire clinique structurée ;
- réaliser un examen cardiovasculaire pertinent ;
- identifier les principaux problèmes ;
- présenter une synthèse argumentée à un senior.

### 1.1 Interrogatoire cardiovasculaire

**Caractériser :**
- douleur thoracique ;
- dyspnée et limitation fonctionnelle ;
- palpitations ;
- malaise / perte de connaissance ;
- œdèmes des MI ;
- symptômes d’insuffisance cardiaque.

**Recueillir :**
- ATCD cardio et généraux ;
- ATCD familiaux pertinents ;
- FDRCV ;
- traitements (posologie, observance) ;
- allergies ;
- habitudes de vie / FDR modifiables.

**Savoir classer** les éléments en : rassurants / à explorer / potentiellement urgents.

### 1.2 Examen clinique cardiovasculaire

- FC, PA ;
- signes de congestion ;
- auscultation cardiaque et pulmonaire ;
- œdèmes périphériques ;
- pouls périphériques ;
- signes d’IC droite et gauche.

**Auscultation :** normal vs anormal ; présence d’un souffle ; systolique vs diastolique ; foyer + irradiation ; situations justifiant des explorations.

### 1.3 ECG en consultation

Lecture systématique :
1. Fréquence  
2. Rythme  
3. Axe  
4. Conduction AV  
5. Largeur des QRS  
6. Repolarisation  
7. Conclusion synthétique  

**Reconnaître :** FA ; tachy/brady significative ; BAV ; blocs de branche ; anomalies de repolarisation ischémiques ; séquelles d’IDM.

---

## 2. Construire le raisonnement clinique

Quatre questions successives :
1. **Quel est le problème principal ?** (une phrase)
2. **Quels sont les éléments cliniques importants ?** (sélection, pas exhaustivité)
3. **Quelles sont les principales hypothèses ?** (hiérarchisées)
4. **Que faut-il faire ensuite ?** examens, urgences, objectifs de prise en charge / prévention

Objectif : **justifier les étapes** — pas la stratégie spécialisée complète.

---

## 3. Présenter un patient à un senior (2–3 min)

1. Identité + motif  
2. Contexte (ATCD, FDR, traitements)  
3. Histoire du problème actuel  
4. Examen (éléments positifs / déterminants)  
5. Examens disponibles  
6. Synthèse  
7. Hypothèses + conduite proposée  

**Compétence centrale :** recueillir → sélectionner → hiérarchiser → synthétiser → proposer.

## 4–10. Échocardiographie transthoracique

**Objectif :** comprendre pourquoi / comment / ce que montre l’ETT — **pas** l’autonomie technique complète.

### Avant l’ETT — 3 questions
1. Pourquoi l’ETT ? (dyspnée, IC, souffle, valve, douleur, rythme, cardiomyopathie, surveillance…)  
2. Quelle question clinique ? (FEVG ? valve sévère ? dilatation ? épanchement ?)  
3. Que vais-je chercher ?

### Incidences à connaître
Parasternale grand / petit axe ; apicales 4 / 2 / 3 cavités ; sous-costale.

### Structures
VG, VD, OG, OD, mitrale, aortique, tricuspide, SIV, péricarde, aorte ascendante, VCI.

### Modes
- 2D → anatomie / mouvement  
- Doppler couleur → flux / régurgitations  
- Pulsé → flux localisé  
- Continu → vitesses élevées (sténose / fuite)

### Les 6 questions face à une ETT
1. Taille du VG ?  
2. Fonction systolique (FEVG) ?  
3. VD normal / dilaté ?  
4. Anomalie valvulaire évidente ?  
5. Épanchement péricardique ?  
6. L’examen explique-t-il la clinique ?

### Pathologies à reconnaître (avec aide)
Dysfonction systolique VG importante ; dilatation VG / cavités droites ; épanchement significatif ; sténose aortique / IM importantes ; autre valve évidente.

### Chaîne à reconstruire
Symptôme → interrogatoire/examen → hypothèses → question à l’ETT → résultats → modification de la prise en charge.

---

## 11. Objectifs pratiques indicatifs

**Consultation :** plusieurs interrogatoires / examens / ECG / présentations orales / synthèses.

**ETT :** assister, identifier incidences et structures, manipuler sous supervision, commenter examens normaux et pathologiques, restituer les conclusions dans le contexte.
