## Modalités d’évaluation

### 1) Contrôle continu
- **1 ou 2 séances d’ARC** pour les camarades (1 h) — planning sur Google Sheet
- Objectifs pédagogiques des livrets (à justifier le jour de l’évaluation)
- Assiduité, attitude, savoir-être

### 2) Évaluation de fin de stage
Présentation **10 min** + **5 min** de questions, sur un **patient que tu as vu** :
1. Motif d’hospitalisation  
2. Antécédents  
3. Histoire de la maladie  
4. Examen clinique  
5. Hypothèses + examens demandés  
6. Résultats + diagnostic  
7. Prise en charge  
8. Suivi  
9. Ce que tu retiens / pourquoi ce patient  
10. Diapo bilan de stage (apprécié / appris / à améliorer)

## Préparation d’un ARC (oral pôle cardio)

### Thèmes à choisir parmi
1. Syndrome coronarien aigu  
2. Endocardite infectieuse  
3. Douleur thoracique  
4. Embolie pulmonaire  
5. Fibrillation auriculaire  
6. Valvulopathies  

Idéal : patient réel + ECG / ETT / ETO / scanner.

### Trame ARC
I. Interrogatoire (constantes, ATCD, traitements, allergies, **FDR cardio**, mode de vie, HDM)  
II. Examen clinique (cardio d’abord ± pneumo, neuro, cutané, abdo)  
III. Hypothèses  
IV. Examens complémentaires  
V. Diagnostic  
VI. Prise en charge  

Envoyer pour **relecture** au médecin référent ARC **tôt** (pas la veille).  
Après l’ARC : un **rapporteur** note les messages clés → fiche de révision pour le groupe.

## Annexe — ARC de cardiologie (checklist)

### Interrogatoire
- **Constantes :** TA (2 bras si suspicion dissection), FC, T°, FR, SpO2
- **ATCD :** médicaux, chirurgicaux, familiaux, gynéco ; âge décès parents si mort subite
- **Traitements / allergies :** traitements actuels ; pilule ; allergie **iode**
- **FDR :** tabac (PA), dyslipidémie, diabète, HTA, surpoids
- **Mode de vie :** tabac, alcool, toxiques, métier, étages, entourage
- **Douleur — LITHIASE :** Localisation, Intensité (EVA), Type, Horaire, Irradiation, facteurs Aggravant/Améliorant, Signes associés, Évolution

### Examen — signes de gravité (toujours)
- Respiratoire : lutte / faillite
- Circulatoire : CPA, pouls paradoxal, hypercapnie, choc, syncope
- Neuro : confusion, agitation, coma

### Orientation diagnostique (réflexes)
| Signe | Orientation |
|---|---|
| Signes d’IVD | EP, tamponnade, IDM VD |
| AVC + fièvre | Endocardite |
| Antéflexion antalgique | Péricardite |
| Jambe rouge | EP |
| Frottement péricardique | Myo/péricardite |
| Souffle d’IA récent | Dissection / EI |
| Signes d’IVG | IDM compliqué, myocardite, valve |
| Asymétrie tensionnelle | Dissection |
| Pouls paradoxal | Tamponnade |

### Examens
- **ECG :** 18 dérivations si douleur thoracique ; méthode **FRACHI**
- **Radio thorax** sauf IDM typique
- **Bio :** bilan standard ; troponine ; BNP ; D-dimères si EP faible/intermédiaire ; GDS/lactate ; β-HCG si femme
- Autres : ETT, EDVMI, angioscanner, coro, FOGD

### Prise en charge (toujours penser)
1. Lieu (USIC / réa / coro…)  
2. Symptomatique (antalgiques…)  
3. Étiologique  
4. Éducation thérapeutique + FDR
