## Vignette

## Correction

Probabilité **intermédiaire/forte** (pilule, voyage, tachycardie, dyspnée, TVP clinique) → **D-dimères inutiles** si forte ; si intermédiaire selon algo local, mais ne pas retarder. Confirmation : **angioscanner** (ou scintigraphie si CI). EDVMI utile.

Stratification : choc/hypotension = haut risque → USIC ± fibrinolyse. Sinon sPESI + signes VD (ETT, bio) pour intermédiaire haut/faible.

Traitement : AOD ou HBPM→AVK selon contexte ; HBPM prolongée si cancer.

---

## Points collège / R2C (à coller)

- Triade Virchow ; TVP → EP fréquente.
- D-dimères **seulement** si proba faible/intermédiaire.
- Haut risque = choc/hypotension.
- Durée anticoagulation : 3 mois si facteur majeur transitoire, plus long si non provoquée.

### Indispensables
- Évoquer EP devant dyspnée + radio normale + contexte.

### Inacceptables
- D-dimères si proba forte.
- Retarder l’angio devant une forte suspicion.

---

## Message clé

**EP : **proba clinique d’abord**, D-dimères ensuite seulement si utiles.**
