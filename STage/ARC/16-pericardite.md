# ARC 16 — Péricardite aiguë

| | |
|---|---|
| **Thème IMM** | Douleur thoracique |
| **Items R2C / collège** | item 235, item 230 |
| **Niveau** | Consult / urgences |

> Entraîne-toi d’abord **sans regarder** la correction (trame ARC : I→VI).

---

## Vignette

Homme de 28 ans, sportif. Douleur thoracique positionnelle, améliorée en antéflexion, virose récente. Frottement. ECG : ST diffus concave, sous-PQ, pas de miroir. Tropo normale. ETT : épanchement minime.

---

## Questions

### III
Critères diagnostiques ? Différence STEMI ?

### VI
Traitement ? Sport ? Hospitalisation ?

---

## Correction

Diagnostic si ≥ 2 critères : douleur typique, frottement, ECG typique, épanchement. Différencier STEMI (ST systématisé + miroir). Traitement : **AINS + colchicine**, repos, arrêt sport jusqu’à guérison. Hospitaliser si critères de gravité (fièvre, gros épanchement, myocardite, immunodépression, traumatisme…).

---

## Points collège / R2C (à coller)

- ST diffus sans miroir + sous-PQ = péricardite.
- AINS + colchicine ; repos sportif.
- Tropo élevée → myopéricardite, ne pas manquer un SCA.

### Indispensables
- Connaître critères et traitement de 1re intention.

### Inacceptables
- Autoriser la compétition trop tôt.
- Prendre une péricardite pour un STEMI (ou l’inverse).

---

## Message clé

**Péricardite : **clinique + ECG**, AINS+colchicine, **sport stoppé**.**
